Leitfaden

        

          

            
1. Daten einrichten

            
Am bequemsten ist der Bereich Yazio Import. Dort hinterlegst du im Profil Benutzername und Passwort und synchronisierst anschließend den vorgeschlagenen Zeitraum.

          

          

            
2. Inkrementell synchronisieren

            
Jeder Import wird als Snapshot gespeichert. Die Arbeitsdateien werden danach konsolidiert. Vollständige Tage schlagen unvollständige Tage; sonst gewinnt der neuere Import.

          

          

            
3. Auswerten

            
Auf der Startseite wählst du einen Tag oder Zeitraum. Die Mahlzeiten werden mit Bestandteilen und Makros angezeigt und lassen sich kopieren.

          

          

            
4. Listen nutzen

            
Im Bereich Listen findest du Produktsuche, Top-100-Lebensmittel, Tage nach Kalorien oder Protein sowie Verdichtungen nach Mahlzeiten, Wochentagen und Monaten. Ein Klick auf ein Lebensmittel zeigt die Verzehrtage; ein Klick auf einen Tag öffnet die Tagesübersicht in einem neuen Tab.

          

          

            
5. Exportieren

            
Excel und PDF übernehmen Name, Geburtsdatum und die Besonderheiten des Tages. Bei Zeiträumen bekommt jeder Tag im Excel eine eigene Tabelle.

          

          

            
6. Manueller Import

            
Der manuelle Import von JSON ist für vorhandene products.json und days.json gedacht. Für den normalen Betrieb ist der direkte Yazio Import besser geeignet.

          

          

            
7. Besonderheiten

            
Notizen pro Tag bleiben lokal erhalten und überleben neue Yazio-Imports, weil sie getrennt von den Yazio-Daten gespeichert werden.

          

          

            
8. Essen oder Getränk

            
Die automatische Zuordnung kann pro Eintrag korrigiert werden. Auf Wunsch merkt sich das Tool die Korrektur für das ganze Produkt.

          

          

            
9. Kaloriengraph

            
Nach einer Bereichsauswertung kannst du den Kalorienverlauf als Graph einblenden. Ein Klick auf einen Punkt springt zum passenden Tag.
